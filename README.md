# Mad devs test Booking app

## How to build

```bash
cp .env.example .env
```

Use pnpm (see package.json).

```bash
pnpm install
```

```bash
pnpm build
```

For start:

```bash
pnpm start
```

## How to run tests

```bash
pnpm test
```

## Что было сделано

1. Компонент отображения календаря в двух видах - месяц, неделя
2. Модальные окна для создания, редактирования, удаления бронирования
3. Осознанно выбран nextjs и app route handlers для создания и реализации синхронного api как in memory state
4. Проверки, валидации, обработки ошибок api и форм обработки бронирования
5. Драг-н-дроп для быстрой смены дату бронирований
6. Просмотр существующего бронирования реализован по ховеру
7. Чуть-чуть адаптивности для мобильных устройств
8. В рамках тестового и исходя из требований сделал выбор, что переговорка одна, и время там всегда московское.
9. Добавил unit тесты на доменно бизнесовую часть
