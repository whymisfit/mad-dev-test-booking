# Mad devs test Booking app

## How to build

Use pnpm (see package.json).

```bash
pnpm install
```

```bash
pnpm build
```

For start:

```bash
pnpm start
```

## How to run tests

```bash
pnpm test
```

## What has been done

Meeting room booking for one room, with a week and month calendar. Bookings are kept in memory for a single Node
process, so separate server instances do not share them.
